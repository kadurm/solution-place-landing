# Solution Place Blindagem — Landing Page Oficial

Repositório dedicado da Landing Page de alta performance e conversão da **Solution Place Blindagem** (Primeira Blindadora Boutique do Mundo).

## Tecnologias
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Carrossel 3D Coverflow com Aceleração por Hardware (GPU)
- Conversão Direta para WhatsApp Oficial
